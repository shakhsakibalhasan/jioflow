যা পরিবর্তিত হয়েছে:
- Notification panel-এর বাইরে ক্লিক করলে বন্ধ হয়; Escape/close-ও থাকে।
- খোলা/visible tab-এ প্রতি ৫ সেকেন্ডে existing heartbeat দিয়ে notification, reset এবং pending approval update হয়। এটি automatic polling; WebSocket নয়।
- Pending ছাড়া login request-এ Approve/Decline দেখায় না। Approve করার পর queue ও notification update হয়; অন্য administrator আগে action নিলে refresh করে handled message দেয়।
- Approve/Decline, reset password, edit account, account security ও অন্য ছোট action corporate modal-এ হয়। Confirmation না দিলে approval RPC চলে না। Customer details/Order-এর বড় work page বজায় থাকে।
- Popup-এ heading/icon, compact form, consistent spacing, rounded border, subtle shadow/backdrop, close/Cancel এবং পরিষ্কার action button। Login-এর recovery popup-ও একই style।
- Save Order: কুরিয়ার নির্বাচন লাগবে না। কোনো কুরিয়ার আগে থেকে নির্বাচন করা থাকলেও Save শুধু confirmed order save করে; method/courier booking পাঠায় না।
- Confirm & Book: valid connected courier লাগবে, confirmation popup হয়, তারপরে booking API। সফল booking server-এর booked flow-তে যায়; ব্যর্থ booking saved confirmed order রেখেই error জানায়।
- Imported/unsupported source-এর কারণে নতুন order save-এ 'Choose a valid source' আর হবে না: নতুন অর্ডারের source supported value-তে normalize হয়; unknown/imported source Phone হিসেবে save হয়। Imported history-এর original source বদলানো হয় না।
- Save Order capsule bar-এ button-এর দুই প্রান্ত গোল; পাশে price-এর দুই দিকে padding।
- Status/assigned badge ও filter tab capsule shape। ছোট selected tab/chip/sidebar/notification action-এ soft background, border ও readable text; বড় Save action-এর brand color বজায় আছে।
- Account list ও profile card-এ avatar বামে, নাম/ইমেইল ডানে।
- Activation-এ একটি Active অথবা Inactive badge। Active soft green, Inactive soft red। Duplicate Active/approval policy line বাদ। Business assignment/verification/access-এর মতো জরুরি warning লালে থাকে।
- Agent Follow-ups expandable submenu: Assigned Customers এবং Permanent Customer। Assigned Customers-এ permanent profile বাদ। Permanent Customer-এ শুধু নিজের permanent profile। Admin/Owner-এর sidebar আগের structure-এ থাকে।
- Permanent Client নাম বদলে Permanent Customer। মূল permission/DB keys বদলানো হয়নি।
